# Offchain Truth

Not yet drafted. How facts from outside the chain get onto it, and how a program verifies them. Planned sections:

## Verifying Signatures from Trusted Sources

How a program verifies the price of SOL: by verifying a signature from a trusted source. Oracles as signed publications of offchain facts; checking the signature, the publisher, the freshness, and the confidence interval exactly as any other input is checked.

## Trust as an Engineering Parameter

Who signs, what it costs them to lie, how stale is too stale, and what the program does when publication stops. The spectrum from a single admin key (the betting market) through multi-party resolution to signed price feeds (lending, perpetual futures).

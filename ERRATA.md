# Errata

Corrections to the published text of *Building Financial Software on Solana*. This file is the source of truth; it is published at [thesolanabook.com](https://thesolanabook.com).

No errata yet: the book is pre-publication, and corrections found before print land directly in the manuscript.

Each erratum, once the book is in print, records: the printing it applies to, the page and section, what the text says, what it should say, and who reported it (credited, with thanks, in the Acknowledgements).
